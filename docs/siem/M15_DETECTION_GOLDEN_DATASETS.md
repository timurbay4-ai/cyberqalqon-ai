# M15 detection golden datasets

`wazuh/fixtures/advanced-detection/m15-golden-v1.json` is generated by
`scripts/export_m15_golden_datasets.py` from the same typed fixtures used by the
quality service. It contains 81 deterministic scenarios: nine for each of
DET-001 through DET-009.

Every rule includes positive, negative, boundary, duplicate, out-of-order,
missing-field, cross-host, cross-account and false-positive-candidate scenarios.
Every record contains `synthetic_test_data=true` and the label
`SYNTHETIC TEST DATA`. Values are realistic but redacted. Cross-host/account
cases that do not apply to an independent single-event rule are explicitly
marked `applicable=false`, not forced into a fabricated classification.

Each fixture declares ground truth, expected finding count, evidence IDs,
explanation fragment, grouping behavior and deduplication behavior. False-positive
candidates are `UNLABELED`: they exercise analyst-review candidates without
pretending that an operational context has trustworthy ground truth.

The framework calls the shared M11 evaluator directly in memory. It does not
ingest fixture events, create production alerts/incidents/cases/notifications,
write Wazuh configuration or mutate the live database. Backend tests verify the
81-scenario shape, explicit labeling, expected outcomes and absence of production
side effects.
